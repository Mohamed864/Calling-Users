Laravel Breeze is a minimal, simple starter kit for Laravel applications that provides a basic authentication system and frontend scaffolding.

What Laravel Breeze Does

Sets Up Authentication

Login

Registration

Password reset

Email verification (optional)

Logout

Provides Frontend Scaffolding

Breeze includes prebuilt UI views using different stacks, depending on your choice:

Blade + Tailwind CSS (default)

Blade + Alpine.js

Inertia.js + Vue

Inertia.js + React

Includes Authentication Routes

Breeze registers all necessary routes under the hood using Laravel’s built-in authentication features.

Minimal & Extendable

It’s not bloated — it gives you only the essentials so you can build your app your way.

Great for learning and for small to mid-size projects.

import defaultTheme from "tailwindcss/defaultTheme";
import forms from "@tailwindcss/forms";

/** @type {import('tailwindcss').Config} */
export default {
    darkMode: "class",
    content: [
        "./vendor/laravel/framework/src/Illuminate/Pagination/resources/views/*.blade.php",
        "./storage/framework/views/*.php",
        "./resources/views/**/*.blade.php",
        "./resources/js/**/*.jsx",
    ],

    theme: {
        extend: {
            fontFamily: {
                sans: ["Figtree", ...defaultTheme.fontFamily.sans],
            },
        },
    },

    plugins: [forms],
};
